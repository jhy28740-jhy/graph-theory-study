# Paulin 可达区域的加权支持函数：独立数学核对

核对者：moment_relaxation。核对日期：2026-10-14。

**结论：PASS，但必须写明目标为 λ₁+kλ₂。** 给定公式是这个目标的支持函数，不是 kλ₁+λ₂，也不是 λ₁+kλ₃。它给每个有限简单图的严格有效上界及最佳渐近线性系数；仅凭这些结果不能宣称解决全部固定 n 的精确最大值或分类全部极图。

## 1. 实际核读的文献范围

Roland Paulin, *Quadratic inequalities between the largest eigenvalues of a graph*, arXiv:2609.37980v1，2026-09-29提交，PDF首页日期2026-09-30。

本次实际核读本地 `s13_checkpoint/sources/2609.37980.pdf.txt` 的 Corollary 2.1（PDF第3页），并对照 `2609.37980.full.txt` 中的同一陈述及后续三块构造证明。该推论明确给有限简单图 n≥2、邻接谱 λ₁≥λ₂≥… 的

    x=(λ₁+1)/n，y=(λ₂+1)/n，
    0≤y≤x，x²+xy+2y²≤x+y。                         (1)

它同时将完整渐近可达区域 R_(1,2) 确定为 (1) 的闭集合，并证明 S_(1,2)=R_(1,2)。这里引用的是已核读预印本的定理，不将“预印本”改写为已核实的期刊发表状态。

本文只独立核验由 (1) 得到的数学推论，不独立重证 Paulin 的二维区域定理。

另以 Sympy 精确运算交叉核对了接触点椭圆恒等式、支持值、二阶导数、k=3 的比例与支持值衔接，以及三块商矩阵特征多项式，六项均通过。符号根式以 q>0、q²=2/(k²−k+2) 表示后作多项式约简，避免把软件未自动化简的根式误判为数学不等。

## 2. 支持函数的直接一元严格推导

定义

    C_k=max{x+k y : 0≤y≤x，x²+xy+2y²≤x+y}，k≥1。

由 (1) 有 0≤y≤1/2。固定 y=t 时，目标严格递增于 x，故取二次约束的较大根

    x(t)=[1−t+√(1+2t−7t²)]/2，0≤t≤1/2。           (2)

该根满足 x(t)≥t，且等号仅在 t=1/2。于是

    F_k(t)=x(t)+kt
          =[1+(2k−1)t+√(1+2t−7t²)]/2，
    F'_k(t)=k−1/2+(1−7t)/(2√(1+2t−7t²))，
    F''_k(t)=−4/(1+2t−7t²)^(3/2)<0。              (3)

特别地 F'_k(0)=k>0、F'_k(1/2)=k−3。严格凹性给：

- 1≤k<3 时有唯一内部最大点；
- k=3 时唯一最大点为 t=1/2；
- k>3 时 F'_k(t)>0，唯一最大点仍为 t=1/2。

在第一段解 F'_k(t)=0，选取符合 7t−1>0 的根，得到

    D=k²−k+2，
    t_k=[1+(2k−1)√(2/D)]/7。                      (4)

此时 2/7≤t_k<1/2，k=3 时公式连续给1/2；最大点的另一坐标为

    x_k=[3+(4−k)√(2/D)]/7。                       (5)

代回得到

    C_k = [k+3+2√(2(k²−k+2))]/7， 1≤k≤3；
    C_k = (k+1)/2，                  k≥3。         (6)

两段在 k=3 都等于2。最大谱对在所述全部范围唯一；“谱对唯一”不等于“实现该谱对的图唯一”。

一个额外交叉核对：椭圆矩阵 A=[[1,1/2],[1/2,2]]，中心 (3/7,1/7)，半径平方2/7，逆矩阵 [[8/7,−2/7],[−2/7,4/7]]。椭圆本身在方向 (1,k) 的支持值正是第一段 (6)；当 k>3 时椭圆接触点越过 x≥y，实际截取区域的最大点固定在 (1/2,1/2)。

## 3. 有限 n 上界及其正确含义

对每个有限简单图 G、n≥2、实数 k≥1，有恒等式

    λ₁(G)+kλ₂(G)=n(x+k y)−(k+1)，

故严格得到

    λ₁(G)+kλ₂(G) ≤ C_k n−k−1。                   (7)

这里 −k−1 来自两条特征值各自平移 +1；不能漏掉，也不能写成只有 −2（除非 k=1）。不要求图连通、不要求 λ₂≥0；有限简单图自动 λ₂≥−1，因而 y≥0。

令 m_k(n)=max_(|V(G)|=n)[λ₁(G)+kλ₂(G)]。可达区域和下节显式构造证明

    lim_(n→∞) m_k(n)/n=C_k。                      (8)

因而 C_k 是最佳渐近线性系数。这不自动等于“对每个 n 都有 m_k(n)=C_k n−k−1”。具体例如 n=2、k=1：只有空图与 K₂，两者 λ₁+λ₂ 都是0，而 (7) 的右端为2/7，严格不等。因此将 (7) 称为全部有限 n 的精确最大值是错误的。

## 4. 三块图的谱和渐近尖锐性

取整数 a≥1、b≥0，n=2a+b，图

    G=K_b ∨ (K_a ⊔ K_a)，                        (9)

其中 ∨ 为完全连接（join），⊔ 为不交并；b=0 时约定删去中心块。为避免与加权参数 C_k、先前研究的谱值 c 混淆，本节把中心块大小写为 b。

对 A_G+I 的三个常数块空间，商矩阵的非零谱为

    α=[a+b+√((a+b)²+4ab)]/2，
    a，
    β=[a+b−√((a+b)²+4ab)]/2；

其余谱为0。b>0 时 α>a>0>β，故 λ₁=α−1、λ₂=a−1。b=0 时两条最大谱均为 a−1，结论连续有效。

置 t=a/n、b/n=1−2t，即两侧团和中心团的比例为

    t,t,1−2t。

得到 (x,y)=(x(t),t)，其中 x(t) 恰为 (2)，故三块图覆盖所需椭圆上边界的有理比例点。

对1≤k<3，取 a_n 为 t_k n 的最近整数、b_n=n−2a_n≥0；充分大的 n 保证 a_n≥1、b_n>0。则 a_n/n→t_k，直接得到 (8)。更精细地，由 F'_k(t_k)=0 和 (3)，

    λ₁(G_n)+kλ₂(G_n)
      =C_k n−k−1−O_k(1/n)。                      (10)

对 k=3，同样取 a_n=floor(n/2)、b_n=n−2a_n∈{0,1}，因 F'_3(1/2)=0，仍有 (10)。因此对1≤k≤3，甚至可写

    m_k(n)=C_k n−k−1−O_k(1/n)，

但这仍不是每个 n 的精确等式。

对 k>3，最优比例固定为 t=1/2；不能继续使用 (4)，因为它会给 t>1/2，使中心质量为负。两个近等大团即可给 m_k(n)=C_k n+O_k(1)，从而 (8)。

## 5. 哪些有限阶情形确实已达到上界

如果1≤k<3，且给定 n 满足 a=t_k n、b=(1−2t_k)n 都为非负整数，(9) 恰取支持点，故达到 (7) 等号，并且这些 n 的精确最大值确实是 (7) 的右端。

例如 k=1 时 t=2/7、中心比例3/7；n=7m 时 K_(3m)∨(K_(2m)⊔K_(2m)) 达到 8n/7−2。k=2 时侧团比例 t=(1+3/√2)/7，不是有理数，不能声称这种等侧三块有限图在某个正整数 n 上恰好达到支持点。

对 k≥3，n 为偶数时 K_(n/2)⊔K_(n/2) 达到 (7) 等号，所以这些参数的有限阶精确值也已确定。

以上都是已证明的等号实例和相应 n 的精确值；没有把三块比例整数条件声称为“所有可能图达到等号的充要条件”。奇数 n 或其他不整除的 n，当前推论没有给一般精确解。

## 6. 能说与不能说的研究结论

可以说：基于 Paulin 已给出的完整区域，λ₁+kλ₂ 的最佳渐近线性系数对所有实数 k≥1 可直接显式求出；有限图通用上界为 (7)，三块图（k≥3时退化为两等团）给尖锐构造，并在上述整数可实现情形严格取等。

不能说：这是 λ₁+λ₃ 问题的解；(6) 是 kλ₁+λ₂ 的同一公式；所有固定 n 的最大值均已求出；所有取等图、所有渐近极图或稳定性都已分类。完整二维谱可达区域只决定支持值与最优谱对，并不自动分类其全部图实现。

若以此选择新课题，仅研究“λ₁+kλ₂ 的渐近最优线性常数（k≥1）”缺少新的数学障碍，因为它已经是 Corollary 2.1 的一元严格凹优化推论。有限 n 的非整除修正、全部等号图或稳定性需要另立问题，并需继续文献核查后才能主张未解决或新颖。
